# Fontes complementares da Rachel IA

Este diretório contém projetos utilizados como fontes técnicas, referências
arquiteturais ou componentes isolados.

## Fontes

- Letta Code — memória persistente e contexto versionado.
- Qdrant — pesquisa vetorial e recuperação semântica.
- Promptfoo — avaliações e testes de aplicações de IA.
- Presidio — identificação e anonimização de dados sensíveis.
- Open Policy Agent — políticas de autorização.
- MCP Python SDK — integração padronizada de ferramentas.
- Playwright MCP — automação estruturada de navegador.
- Tauri — construção da aplicação desktop.
- openWakeWord — ativação local por palavra-chave.

## Regras de incorporação

1. Preservar licenças, avisos e autoria.
2. Não copiar projetos integralmente para o núcleo da Rachel.
3. Registrar quais componentes foram efetivamente aproveitados.
4. Isolar ferramentas e serviços por processo.
5. Fixar versões utilizadas.
6. Executar ferramentas externas com permissões mínimas.
7. Solicitar aprovação antes de ações sensíveis.
8. Não incluir dados privados em avaliações ou treinamentos sem autorização.
9. Revisar novamente as licenças antes de qualquer distribuição comercial.
