# Changelog

## 0.2.0 — 2026-08-14

- identidade visual do núcleo luminoso integrada ao pacote;
- animações de flutuação, rotação orbital e pulsação central;
- partículas de luz responsivas em Canvas;
- estado visual de processamento sincronizado com o chat;
- interface responsiva e campo de mensagem compacto;
- acessibilidade para movimento reduzido;
- teste automatizado do arquivo visual empacotado.

## 0.1.1 — 2026-08-14

- fechamento explícito das conexões SQLite para compatibilidade com Windows;
- interface web provisória servida em `/`;
- teste de regressão da interface local.

## 0.1.0 — 2026-08-14

- domínio e contratos iniciais;
- chat persistente;
- memória SQLite com migrations;
- provedor simulado offline;
- adaptador para APIs de chat compatíveis;
- auditoria JSONL com mascaramento;
- política negar por padrão;
- CLI, diagnóstico e API HTTP local;
- listagem, exportação e exclusão de conversas;
- testes automatizados de núcleo e API.
